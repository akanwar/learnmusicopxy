How this course teaches (the science, briefly)

Four habits are built into every session, because the research on learning is unambiguous about them:

  • Warm-ups make you remember before you re-read. Recalling something strengthens memory far more than reviewing it (the testing effect) — always try the warm-up before scrolling back.
  • Quizzes close each week. Answer out loud first, then click to check. Being almost right and then corrected is exactly where memory forms.
  • Short sessions, spread out. Two or three 30-minute sessions beat one 3-hour marathon (the spacing effect). Stop while it is still fun.
  • Every session ends with something you can play. Hearable progress is the motivation that survives to week 12.
